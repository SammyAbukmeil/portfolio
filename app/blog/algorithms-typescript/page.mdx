# Algorithms in TypeScript

Algorithms are a **sequence of steps to solve a problem**. Given the same steps + inputs, an algorithm should always lead to the same solution.

## Measuring Performance

Since a problem may have multiple solutions, we often measure the performance of an algorithm to compare. Consider the following problem:

> Build a function which:
> 1. Takes a number as an input
> 2. Calculates the sum of all numbers leading up to that number

A solution might look like the following:

  style={{ height: "17rem" }}
  src="https://codesandbox.io/embed/r4mzpz?view=editor+%2B+preview&view=split&previewwindow=console&fontsize=12"
></iframe>

You might be tempted to measure the performance via the [Performance API](https://developer.mozilla.org/en-US/docs/Web/API/Performance)

> Note:
> - You can change the number in the example below (e.g. `30`), however, **be careful not to input large values** otherwise your browser will crash (don't go above 300m `300000000`)
>
> - Small numbers show `0` since it runs too fast and finishes in less than a millisecond.

<iframe
  style={{ height: "22rem" }}
  src="https://codesandbox.io/embed/h5zl76?view=editor+%2B+preview&view=split&previewwindow=console&fontsize=12"
></iframe>

As you make the number bigger, you'll notice that the time it takes increases. However, try the same number twice, it's always slightly different. This is due to various factors:

- The speed of the computer
- The amount of processes running on your computer
- The ram your browser has availble

So this isn't the best way to measure the performance of an algorithm. However, as you add `0`'s to the example above, we do see a trend, roughly:

- 1
- 10
- 100
- 1000

It's a factor of 10 (if we x10 the input, the time it takes to finish is x10 longer). Similarly, if we x2 the input, the time is x2.

This is called **linear time complexity**. This is how it would look on a graph:

![Linear Time Complexity](/algorithms/linear-time-complexity.png)

As `n` grows -> more loop iterations -> more time (in a linear way)
