# Algorithms in TypeScript

Algorithms are a **sequence of steps to solve a problem**. Given the same steps + inputs, an algorithm should always lead to the same solution.

## Measuring Performance (bad approach: manually timing it)

Since a problem may have multiple solutions, we often measure the performance of an algorithm to compare. Consider the following problem:

> Build a function which:
> 1. Takes a number as an input
> 2. Calculates the sum of all numbers leading up to that number

## Measuring Performance (better approach: spot a trend)

In the example above, as you add `0`'s, we see a trend which is roughly:

- 1
- 10
- 100
- 1000

It's a factor of 10 (if we x10 the input, the time it takes is x10 longer). Similarly, if we x2 the input, the time it takes is x2. 

In other words, as the input increases, so does the time in a linear fashion. This trend is called **linear time complexity**. This is how it would look on a graph:

## Measuring Performance (best approach: Asymptotic Analysis)

Asymptotic Analysis is a technique to figure out if an algortim is Linear (`O(n)`), Constant (`O(1)`) etc.

It involes 3 steps:
1. Figure out the mathematical "function", which allows us plot the trend on a graph
2. ...
3. ...

Let's use Asymptotic Analysis for this function:

```ts
function sum(n: number) {
  let result = 0;

  for (let i = 0; i <= n; i++) {
    result += i;
  }

  return result;
}
```

To figure out the mathematical function, we need to **count the number of expression executions**.

Let's start off by checking how many times each expression executes when `n` is `1`:

```ts
function sum(n: number) {
  let result = 0; // 1

  for (let i = 0; i <= n; i++) { // 1
    result += i; // 1
  }

  return result; // 1
}
```

The mathematical "function" is written like so:

`T = 1 + 1 + 1 + 1`

```ts
function sum(n: number) {
  let result = 0; // 1

  for (let i = 0; i <= n; i++) { // 1
    result += i; // 3
  }

  return result; // 1
}
```

So the only thing that changes when `n` increases is the amount of times the expression in the body of the loop.
